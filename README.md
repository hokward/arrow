🏹 Arrow
Arrow is a fast-paced 2D survival and action game built using the Godot Engine. Navigate a vibrant world, survive relentless chasing enemies, rack up high scores, and test your reflexes!

🎮 Features
Start Menu & Pause State: Clean start screen featuring a clickable "PLAY GAME" button that unpauses the gameplay loop right when you are ready.

Dynamic Score Tracking: Real-time UI score counter that updates instantly as you progress.

Endless Enemy Spawning: Automated respawn system that keeps the pressure high by introducing new monsters onto the battlefield.

Survival & Reset Loop: Smart enemy tracking physics. If a monster catches you, the game instantly triggers a fresh restart.

🛠️ Built With
Engine: Godot Engine (GDScript)

Assets: Custom 2D sprites and backgrounds

🕹️ How to Play
Run the game in Godot (F5).

Click the PLAY GAME button on the start screen to unfreeze the action.

Move around to avoid the tracking monsters.

Defeat enemies and survive as long as possible to push your score to the max!
